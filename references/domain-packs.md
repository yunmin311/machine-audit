# Domain Packs · 领域线索种子库（machine-audit/reference）

> **定位（v0.5 修正）**：这不是分类学，是**线索种子库**。用途：给 auditor 的运行时探索提供起点——命中任何信号只代表"往这个方向探索"（这台机器大概率还承担什么角色、有哪些领域特有的黑洞），不代表机器被分类完成。真实机器几乎都是复合体（乱七八糟都有是常态），种子库的职责是把探索的扇面打开，而不是收拢。
> **使用规则**：① 命中信号 → 按该包的"专项"扩大探索 → ② 探索中新发现的软件/领域 → 运行时搜索（web）补全范式并写进本轮报告 → ③ 确认的新模式回写 overlay（自我积累）。④ 未命中任何包 = 通用流程跑，不是"没救了"。
> 每包格式：**信号**（线索）→ **专项**（该领域常见黑洞与雷区）→ **权重/注意**（口径调整建议——建议而非规则）。

## A. 开发类

### A1 Web 全栈
信号：`node_modules`/`package.json`/`.vercel`/`pnpm-workspace`/多个浏览器 Beta 版
专项：node_modules 总量与孤儿仓（package.json 已删目录还在）；端口占用矩阵（3000/5173/8080 互抢）；`.env` 与 git 历史泄漏；浏览器多配置文件膨胀
权重：阶段 4↑↑、阶段 10↑

### A2 移动开发
信号：`Android Studio`/`adb`/`gradle`/`.android`/模拟器
专项：SDK/NDK 多版本；模拟器与 Hyper-V/VBS 冲突（ famously 互斥）；ADB 设备驱动；APK/镜像堆积
权重：阶段 5↑（模拟器即虚拟机）

### A3 游戏开发
信号：Unity Hub/Unreal Editor/Godot/`.unity`/`.uproject`
专项：引擎多版本与派生缓存（Library/Intermediate/DerivedData）；资产库体积；Perforce/git-lfs 配置
权重：阶段 2 深度↑（资产动辄百 GB）

### A4 数据科学 / ML
信号：conda/`.venv`/Jupyter/CUDA/tensorflow/数据集目录
专项：CUDA/cuDNN/驱动版本矩阵（匹配地狱）；conda 环境膨胀（单环境 5GB+）；数据集与 checkpoint 目录（常无人管）；Jupyter kernel 残留
权重：阶段 1（GPU/驱动）↑↑、阶段 4↑

### A5 DevOps / 自托管
信号：docker-compose/k8s yaml/frp/内网穿透/证书目录
专项：镜像与卷堆积（docker system df）；端口映射冲突；证书过期扫描；frp/穿透的安全面
权重：阶段 7↑、阶段 16↑

### A6 桌面/.NET
信号：VS 全家/`.sln`/dotnet SDK 多版本
专项：SDK 层层叠（每版 1-2GB）；MSBuild/VS 缓存；Windows Kits 重复安装
权重：阶段 4↑

### A7 安全研究
信号：靶场 VM/Burp/nmap/渗透工具目录
专项：**AV 误报极高——工具白名单声明优先**；隔离网络确认；法律边界声明
权重：阶段 7 口径反转（"危险工具"在此是合法资产）

### A8 DBA
信号：SSMS/DBeaver/数据库服务/备份目录
专项：数据目录膨胀、备份代数、端口暴露（阶段 7 联动）
