# Stage 03 · 磁盘规则符合度

## 目的
若 overlay `rules_file` 配置了本机磁盘规则（该文件是可选的本机磁盘规则——命名/结构/快照，无规则则跳过本阶段 §3.1，只跑 §3.2 通用检查），验证目录结构与命名是否守约。

## 3.1 规则符合度（有 rules 时）
- 顶层目录对照：规则外的无前缀新增目录 = 违规记录（限期归位建议）。
- 冻结名单核对：被工具/服务引用的路径是否被移动过（`Test-Path` + 服务 PathName 交叉）。
- 临时区体量 vs 阈值；带日期快照目录超期清单；下载 inbox 积压。

## 3.2 通用命名/结构检查（v0.6：无规则机器只提示不判违例）
- 命名观察（**仅在 overlay `rules_file` 配置了命名规则时才算"违例"**，否则只是提示）：目录名含 `?`/`#`/尾随点/乱码特征字（鎴/涓/锛 高频=GBK 事故，处置需 `\\?\` 前缀）；空格本身不算违例（大量正规软件目录带空格），只在规则明确禁用时记录。
- `(1)(2)` 重复副本模式、纯时间戳目录、大文件归属不明——保持为"清单+建议"。
- `(1)(2)` 重复副本模式扫描：`Group-Object Name` 同名 >1 且均为用户文件 → 列"择优"清单。
- 工具生成的纯时间戳目录（`2026-10-18-12-31-03` 类）清单。
- 大文件 top20 的归属定性（媒体/游戏库/安装包/未知——未知即探索任务）。

## 输出
违规表（项/规则依据/建议去向/风险标注"动前需复核引用"）。规则文件本身不存在时输出一行"未配置规则，仅通用检查"——不造规则、不替用户决定目录哲学。
